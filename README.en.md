# 🐱 Our Cats

**English** | [中文](README.md)

> Give your cat cyber immortality!

An open memorial story collection: anyone can write down the story between them and their cat.
Stories live in this repository as Markdown files, and the website automatically renders every story into a card on the homepage.
Let's remember our cats' stories, together.

## 🔗 Visit

- 中文版：**https://z-orzi.github.io/OurCatsLiveForever/**
- English：**https://z-orzi.github.io/OurCatsLiveForever/en/**

## ✏️ Share your story (no coding required)

👉 **[AI Upload Guide](AI_UPLOAD_GUIDE.md)** (in Chinese): copy the prompt, send it to any AI (Kimi, ChatGPT, DeepSeek, etc.), and the AI will write the story file for you — you just paste and commit it on the GitHub website.

## 📁 Repository structure

```
src/content/stories/   ← all stories live here (one folder per person)
public/images/         ← cover photos
```
