# 🐱 我们的咪

> 让咪获得赛博永生！

这是一个开放的纪念故事集：任何人都可以写下自己和小猫的故事。
故事以 Markdown 文件的形式存放在本仓库中，网站会自动把每篇故事渲染成首页的一张卡片。
小猫的故事我们一起记住。

## 🔗 在线访问

**https://z-orzi.github.io/OurCatsLiveForever/**
（部署完成后，把这里替换成你的实际地址）

## ✏️ 如何分享你的故事（无需任何代码）

👉 **[AI 上传指南](AI_UPLOAD_GUIDE.md)**：复制一段提示词发给任意 AI（Kimi、ChatGPT、DeepSeek 等），
AI 会帮你写好故事文件，你只需在 GitHub 网页上粘贴并提交即可。

## 📁 目录结构

```
src/content/stories/   ← 所有故事都在这里（每人一个文件夹）
public/images/         ← 封面照片
```
